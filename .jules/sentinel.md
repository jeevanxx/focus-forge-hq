## 2025-05-22 - CSS Injection in Shadcn Chart Component
**Vulnerability:** The `ChartStyle` component in `src/components/ui/chart.tsx` used `dangerouslySetInnerHTML` to inject CSS variables directly from the `config` object without sanitization. An attacker could provide a malicious color value or key (e.g., `red; } body { background: red; }`) to break out of the CSS rule and inject arbitrary styles, potentially leading to UI redressing or exfiltration of data via CSS.
**Learning:** Even internal-looking configuration objects can be a source of injection if their properties are used to construct raw HTML or CSS. Sanitizing both keys and values is necessary when they are used as part of a CSS rule.
**Prevention:** Whitelist alphanumeric characters for IDs used in selectors. Blacklist or escape characters that have special meaning in CSS (e.g., `; { } < > \`) for dynamic keys and values. Use quoted attribute selectors (`[data-chart="id"]`) to prevent selector breakouts.
