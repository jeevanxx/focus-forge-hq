## 2026-05-11 - CSS Injection in Shadcn ChartStyle DangerouslySetInnerHTML
**Vulnerability:** Untrusted/dynamic properties (id, keys, colors) inside the dynamically generated `<style>` tag of the Shadcn UI `ChartStyle` component can lead to CSS Injection or arbitrary HTML breakout if passed to `dangerouslySetInnerHTML` without proper sanitization.
**Learning:** Standard static analysis tools often miss style-tag injection in React because the styling is dynamically evaluated inside template strings within `dangerouslySetInnerHTML`. Sanitizing dynamic parts with regexes that block breakout characters (such as `;`, `{`, `}`, `[`, `]`, `"`, `'`, `<`, `>`, `\`) keeps Tailwind theme tokens (like `hsl()` or `var()`) intact while rendering style breakouts impossible.
**Prevention:** Always write local non-exported sanitizers for dynamic CSS variables or dynamic stylesheet generation. Verify and test styling security by mocking Recharts ResponsiveContainer layout constraints with a localized `ResizeObserver` mock in the test files.
