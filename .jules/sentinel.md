## 2026-10-03 - Unauthenticated Edge Function Invocation and CSS Variable Injection
**Vulnerability:** `overdue-push` edge function accepted unauthenticated HTTP requests while executing database queries and web push notifications with `SUPABASE_SERVICE_ROLE_KEY`. Additionally, `ChartStyle` in `chart.tsx` injected unsanitized config keys and colors into CSS custom properties inside a `<style>` tag.
**Learning:** Edge functions deployed on Supabase are publicly accessible by default unless `Authorization` header validation against `SUPABASE_SERVICE_ROLE_KEY` or `auth.getUser(token)` is explicitly enforced. Chart components using `dangerouslySetInnerHTML` for CSS custom property generation require strict string sanitization (`/[^a-zA-Z0-9_-]/g` for keys/IDs and stripping breakout characters plus blocking `url()` constructs) to prevent CSS injection, XSS, and tracking pixel exfiltration.
**Prevention:** Always validate `Authorization` headers in Supabase edge functions that perform privileged operations, and sanitize all dynamic values before embedding them into raw CSS or HTML blocks.
