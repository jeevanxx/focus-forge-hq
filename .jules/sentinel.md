## 2025-03-05 - CSS and HTML Injection in ChartStyle Component
**Vulnerability:** The `<ChartStyle>` component in `src/components/ui/chart.tsx` takes dynamic values from chart configuration keys and colors and embeds them directly into a raw CSS string inside a `<style>` tag using `dangerouslySetInnerHTML`. Because these values (specifically `config` keys, `id` attribute, and `color` variables) are not sanitized, a malicious payload could inject arbitrary CSS rules or break out of the style tag entirely to inject arbitrary HTML, potentially leading to Cross-Site Scripting (XSS).
**Learning:** Dynamic CSS values placed inside `dangerouslySetInnerHTML` require strict sanitization before output. Even when developers assume input is safe, library consumers or future dynamic data-binding can expose these components to unvalidated input.
**Prevention:** Always sanitize dynamic identifiers and values used to generate inline `<style>` tags. Restrict CSS selectors and property names (like `--color-${key}`) to alphanumeric characters, dashes, and underscores. For values like colors, block or strip CSS breakout characters (e.g., `; { } [ ] " ' < > \ @ :`) to prevent arbitrary rule injection while permitting valid CSS color syntax (such as spaces for modern color functions).
