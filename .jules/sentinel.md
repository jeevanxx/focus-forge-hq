## 2026-08-05 - Chart Style CSS and SSRF Injection Remediation
**Vulnerability:** The `<ChartStyle>` component in `src/components/ui/chart.tsx` injected dynamic keys, IDs, and color values directly into a `<style>` element using `dangerouslySetInnerHTML` without validation. Attackers controlling these values could inject arbitrary CSS, perform HTML/styling breakouts, or leak user tokens/data via SSRF or tracking pixel requests (e.g., using `url()` constructs).
**Learning:** Standard shadcn chart configurations often assume all data keys and values are hardcoded. However, in applications rendering dynamic charts with user-provided categories or themes, unvalidated values lead directly to CSS Injection, breakouts, and tracking risks.
**Prevention:** Always sanitize any dynamic properties used inside raw CSS style blocks. Restrict keys and IDs to alphanumeric characters, dashes, and underscores (`/[^a-zA-Z0-9_-]/g`), and strictly filter out breakout characters (`; { } [ ] " ' < > \ \`) and `url()` constructs in color values.
