## 2025-03-09 - Chart Style Injection Security Sanitization
**Vulnerability:** Insecure CSS / HTML Style Injection via Recharts Config in `chart.tsx`. The component used `dangerouslySetInnerHTML` to inject custom themes and colors without sanitization. An attacker could supply malicious chart configuration keys, IDs, or color strings containing CSS breakouts or SSRF-triggering `url()` constructs.
**Learning:** Modern component libraries (like shadcn/ui) often dynamically generate `<style>` tags using raw object properties. When these properties originate from user-controlled inputs or unsanitized database fields, it opens risks of CSS Injection, Cross-Site Scripting (XSS), and blind SSRF via pixel trackers.
**Prevention:** Apply strict sanitization helpers to dynamic configuration properties injected into styling templates. Whitelist IDs and property keys to `/[^a-zA-Z0-9_-]/g`, block SSRF/tracking risks by filtering out CSS `url()` expressions, and filter critical styling breakout characters (such as `; { } [ ] " ' < > \`) from variable values while retaining safe color formatting characters like parentheses for `hsl()` functions.
