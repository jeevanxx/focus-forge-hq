## 2025-05-22 - CSS Injection in Chart Component
**Vulnerability:** Dynamic CSS generation via `dangerouslySetInnerHTML` in the `ChartStyle` component (`chart.tsx`) was vulnerable to CSS rule and declaration injection. Malicious IDs, config keys, or color values could break out of their intended scopes and inject arbitrary CSS (e.g., `] { background: red; } body { ... }`).
**Learning:** Even internal-looking UI components can be vectors for injection if they use `dangerouslySetInnerHTML` to generate `<style>` tags from props. Sanitizing IDs to a strict alphanumeric/dash/underscore set and filtering color values to block rule-breakout characters (`; { } [ ] " ' :`) is essential. Using quoted attribute selectors (e.g., `[data-chart="${id}"]`) provides an extra layer of defense against selector-based injection.
**Prevention:** Always sanitize any dynamic content injected into `<style>` tags or other raw HTML contexts. Use strict allow-lists for characters where possible, and block known breakout characters otherwise.
