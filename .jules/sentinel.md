## 2025-05-18 - CSS and HTML Injection in Chart Component Style Tag
**Vulnerability:** Unsanitized dynamic properties (such as element IDs, configuration keys, and CSS color values) were passed directly to a custom `<style>` element using `dangerouslySetInnerHTML` inside `src/components/ui/chart.tsx`. An attacker who can control configuration keys or dynamic IDs could break out of the style rule context or inject malicious HTML (like SVG styles or script tags).
**Learning:** React elements utilizing `dangerouslySetInnerHTML` for custom `<style>` rules bypass normal JSX sanitization. Standard UI components often utilize user-supplied or database-driven config object keys and properties to construct styling variables.
**Prevention:** Always restrict dynamically generated CSS variable keys to alphanumeric characters, dashes, and underscores. For color and design variables, strictly strip breakout characters (like `; { } [ ] " ' < > \ \``) before injecting them into dynamic style tags.
