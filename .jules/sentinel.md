## 2026-06-25 - [HIGH] Fix CSS Injection and XSS in Chart component
**Vulnerability:** The `ChartStyle` component used `dangerouslySetInnerHTML` to inject dynamic CSS rules without sanitizing the `id`, configuration keys, or color values. This allowed for CSS injection and potential XSS by breaking out of the `<style>` tag.
**Learning:** Dynamic CSS generation in React components using `dangerouslySetInnerHTML` is a powerful but dangerous pattern. Every dynamic part of the CSS string must be strictly sanitized. IDs should be restricted to a safe set of characters (alphanumeric, dashes, underscores), and CSS values should block characters that allow declaration or rule breakout (`; { } [ ] " ' : \ < >`). Additionally, attribute selectors in CSS should be quoted to prevent attribute breakout.
**Prevention:** Always sanitize dynamic inputs used in `dangerouslySetInnerHTML`. Use strict allow-lists for identifiers and deny-lists for characters with special meaning in CSS/HTML contexts. Prefer CSS-in-JS libraries or standard CSS modules where possible, but if manual string generation is required, treat it as a high-risk area.
