## 2026-11-01 - Dynamic CSS and DOM Attribute Injection in Shadcn ChartStyle
**Vulnerability:** The `ChartStyle` component interpolated raw configuration keys, colors, and chart IDs into inline `<style>` tags via `dangerouslySetInnerHTML` without character escaping or validation. An attacker controlling configuration values or theme colors could inject CSS rules to break out of declarations, hijack DOM elements, or perform SSRF / tracking pixel exfiltration via `url(...)`.
**Learning:** React component libraries using dynamic styling directly in HTML templates often assume that configuration objects are hardcoded constants. When theme or chart configurations are dynamic or derived from user input, unescaped interpolation leads to CSS injection and DOM attribute escaping issues.
**Prevention:** Always sanitize dynamically generated CSS selectors, property names, and property values against syntax breakout characters (`;`, `{`, `}`, `[`, `]`, `"`, `'`, `<`, `>`, `\`). Disallow external network fetching vectors like `url(...)` in user-configurable styling parameters.
