## 2026-07-20 - CSS and HTML Injection in ChartStyle via dangerouslySetInnerHTML
**Vulnerability:** The `<ChartStyle>` component used `dangerouslySetInnerHTML` to dynamically render custom styling definitions based on incoming user configurations (including container IDs, config keys, and CSS color strings). Breakout characters like `;`, `{`, `}`, `<`/`>` in these fields allowed injecting arbitrary CSS rules (which can leak data or conduct UI redressing) or closing the `<style>` block to inject malicious `<script>` tags.
**Learning:** Utilizing raw values inside `<style>` blocks with `dangerouslySetInnerHTML` poses high security risks. Because of the context, standard HTML escaping does not protect against CSS syntax breakouts, and standard CSS escaping can be tricky. It is much safer to sanitize input variables with strict whitelists or blacklist breakout characters.
**Prevention:** Sanitize container IDs and custom property keys to contain only safe alphanumeric characters, hyphens, and underscores. For CSS colors, blacklist breakout characters (`; { } [ ] " ' < > \ @ :`) while still allowing standard alphanumeric values, `#`, parentheses, commas, periods, and spaces to support HSL, RGB, and RGBA functions.
