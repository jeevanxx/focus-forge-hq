## 2025-03-01 - Optimizing getWeeklyFocus using Single-pass Accumulation
**Learning:** Performing multiple filters and reductions on the same array in standard loop structures inside React render trees or performance-sensitive computations scales poorly. The original code filtered the focus sessions seven times (once per weekday), resulting in an O(7N) performance profile. By pre-filling the result array with zero-initialized entries and doing a single-pass O(N) iteration over the sessions, we avoided repeated filter evaluations.
**Action:** When aggregating dynamic metrics (e.g. time series, calendar-based charts), avoid multiple sub-array filtrations in a loop. Instead, construct a pre-filled target map or array first, then iterate over the dynamic collection in a single pass to map or accumulate items. Use timezone-safe functions like `differenceInCalendarDays` for reliable offsets.
