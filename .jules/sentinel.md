## 2025-05-18 - Sanitizing Dynamic CSS in Custom Stylesheets
**Vulnerability:** Arbitrary CSS rule breakout and HTML tag injection through unsanitized dynamic styling variables passed to `<style dangerouslySetInnerHTML={...}>` in React.
**Learning:** React elements naturally escape standard properties, but inside `<style>` tags with `dangerouslySetInnerHTML`, text is parsed as literal CSS stylesheet definitions. Any unescaped characters like `;`, `{`, `}`, `[`, `]`, `"`, `'`, `<` or `>` can be utilized to close style blocks, declare arbitrary malicious selectors/properties, or inject close-tags like `</style><script>...</script>` for XSS.
**Prevention:** Always restrict dynamically generated CSS class or attribute selectors using strict alphanumeric/dash/underscore filters (e.g. `/^[a-zA-Z0-9_-]+$/`). For property values like color variables, sanitizers must strip critical CSS breakout characters (`/;{}[\]"<>\\`'/`) while leaving standard color function operators intact.
