## 2025-05-15 - Dynamic CSS Custom Property Injection in Charting Components
**Vulnerability:** User-controlled inputs or theme configuration keys mapped directly to CSS selector IDs, custom property keys, and property values inside a raw `<style>` tag can lead to CSS breakout. An attacker providing special characters like `;`, `{`, `}`, and HTML tag structures can close the declaration block and inject arbitrary CSS rules or execute Cross-Site Scripting (XSS) in some environments.
**Learning:** React's `dangerouslySetInnerHTML` on a `<style>` element allows raw string interpolation, completely bypassing standard React DOM escaping protections. When rendering inline style elements based on dynamic theme configuration structures, typical React protections do not apply.
**Prevention:** Always implement strict whitelisting and character elimination on any dynamic values mapped inside CSS custom property blocks. Selector IDs and variable keys must strictly allow only safe CSS identifier characters (such as alphanumeric, dashes, and underscores via `/[^a-zA-Z0-9_-]/g`). Property values (such as colors) must completely strip critical breakout delimiters like `;`, `{`, `}`, `[`, `]`, `"`, `'`, `<`, `>`, and `\` to prevent syntax escaping while retaining valid parentheses for modern CSS functional notations like `var()` or `hsl()`.
