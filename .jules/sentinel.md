## 2025-03-09 - CSS and HTML Injection in Dynamic ChartStyle Blocks
**Vulnerability:** Unsanitized chart ID, config keys, and color values were injected directly into a `<style>` element using `dangerouslySetInnerHTML`. Since these properties could be influenced by external or dynamic configurations, a malicious actor could break out of the style rule (e.g., using `;`, `{`, `}`) to perform CSS Injection or close the style block (`</style>`) to execute arbitrary Cross-Site Scripting (XSS).
**Learning:** Reusable library components like `chart.tsx` often generate custom CSS dynamically to support theme configurations. If these styles are rendered via HTML interpolation inside React (`dangerouslySetInnerHTML`), they bypass React's default safe string escaping, necessitating strict local sanitization.
**Prevention:** Always sanitize dynamic inputs injected into `<style>` strings. Restrict IDs and keys to simple alphanumeric/underscore classes (`/[^a-zA-Z0-9_-]/g`), and strictly strip breakout sequences (`;`, `{`, `}`, `<`, `>`, etc.) from color values while preserving valid color function characters like parentheses, commas, and dots.
