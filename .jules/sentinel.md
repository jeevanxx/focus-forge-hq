## 2025-03-05 - Inline Style Injection Vulnerability in Shadcn Chart Component
**Vulnerability:** In `src/components/ui/chart.tsx`, user-provided `id`, config key, or `color` strings were interpolated directly into an inline `<style>` element rendered via `dangerouslySetInnerHTML`. This allowed potential HTML breakout or CSS injection/XSS.
**Learning:** Checking for the presence of `;` or `{` in style content assertions fails because the generated template code itself contains trailing structural semicolons and braces. Tests must target the injected strings specifically to avoid false positives. Additionally, testing components that depend on Recharts requires mocking `ResizeObserver` in the test setup.
**Prevention:** Always restrict custom property keys and chart IDs to alphanumeric and standard safe delimiters (`_` or `-`). Strip hazardous breakout characters like `;`, `{`, `}`, `[`, `]`, quotes, angle brackets, and backticks from user-supplied color values while keeping parenthesis for custom/flexible CSS functional notations.
