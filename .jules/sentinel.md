## 2025-06-15 - Dynamic CSS Injection in Tailwind/Shadcn Charts
**Vulnerability:** Dynamic chart styles inside `ChartStyle` inject un-sanitized keys, custom properties, and colors using a dynamic style block with `dangerouslySetInnerHTML`. An attacker providing malicious configuration keys, container IDs, or hex/rgb color values could break out of CSS selectors to inject arbitrary CSS rules, hijack styles, or perform XSS via style block tag breakout.
**Learning:** React components that dynamically generate CSS strings using `dangerouslySetInnerHTML` must sanitize all values. In this flat ESLint environment, escaping `<` or `>` inside regex patterns causes `no-useless-escape` errors, requiring us to avoid backslash escapes inside character classes. Testing charting components in Vitest also requires polyfilling/mocking `ResizeObserver` inside `src/test/setup.ts`.
**Prevention:** Always strictly sanitize dynamic identifiers (using `/[^a-zA-Z0-9_-]/g`) and sanitize dynamic CSS property values (removing breakout characters such as `;{}|[]"'\<\>\\@:` while permitting safe color syntax characters). Never export sanitization helpers inside component files to avoid ESLint Fast Refresh warning triggers.
