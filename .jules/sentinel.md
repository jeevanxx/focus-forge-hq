## 2025-02-18 - CSS Selector and Variable Injection in ChartStyle
**Vulnerability:** Unsanitized ID, config keys, and color values were rendered directly into raw HTML inside a `<style>` block via `dangerouslySetInnerHTML`. An attacker could inject breakout characters like `] { ... }` or HTML tag delimiters `</style><script>...` to achieve arbitrary styling/rule injection or Cross-Site Scripting (XSS).
**Learning:** Recharts theme-based color mappings require dynamic CSS generation using inline style blocks. Injecting dynamic, unvalidated properties inside `dangerouslySetInnerHTML` of a style block bypasses React's built-in XSS and HTML escaping, exposing the DOM to style and markup breakout.
**Prevention:** Always sanitize dynamic identifiers and property keys using restrictive whitelists (such as `/^[a-zA-Z0-9_-]+$/`). Sanitize arbitrary CSS values (like colors) by stripping breakout characters (`;`, `{`, `}`, `[`, `]`, `"`, `'`, `<`, `>`, `\`) before outputting them to raw inline styles.
