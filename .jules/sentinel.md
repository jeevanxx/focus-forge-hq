## 2025-07-25 - CSS Injection and HTML Breakout in ChartStyle
**Vulnerability:** React components rendering inline `<style>` tags with `dangerouslySetInnerHTML` containing dynamic or developer-defined keys and values can suffer from XSS and CSS injection if keys or color values are not strictly sanitized.
**Learning:** The dynamic color and custom property generation in shadcn chart styling bypassed default React HTML/CSS sanitization via `dangerouslySetInnerHTML`. Because dynamic keys (which may be derived from arbitrary strings) and dynamic color expressions were interpolated directly into raw CSS templates, curly braces, semicolons, and angle brackets allowed an attacker/developer to break out of CSS rule scopes and inject arbitrary CSS rules or execute arbitrary script tags.
**Prevention:** Always sanitize any dynamic properties injected into raw `<style>` blocks using strict whitelists (e.g. alphanumeric, hyphens, and underscores for CSS variables/selectors) and block/strip critical breakout characters like `;`, `{`, `}`, `[`, `]`, `"`, `'`, `<`, `>`, and `\` from color strings.
