## 2025-02-23 - CSS Injection and SSRF via Dynamic CSS in Chart Component
**Vulnerability:** In `src/components/ui/chart.tsx`, `ChartStyle` dynamically interpolated `id`, `config` keys, and `color` strings directly into a raw CSS string inside `<style dangerouslySetInnerHTML={{ __html: ... }} />`. Unsanitized values allowed arbitrary CSS rule injection, DOM/HTML breakout, and potential unauthorized external HTTP GET requests (SSRF/tracking pixel leaks) via `url()` CSS constructs.
**Learning:** React's standard JSX escapes strings inside HTML attributes/content, but content inside `dangerouslySetInnerHTML` bypasses React's sanitization entirely. CSS style sheets require strict validation of custom property names and values because characters like `;`, `}`, quotes, or `url()` allow injection of entirely new CSS declarations or external image requests.
**Prevention:** Robustly sanitize dynamic inputs before injecting into inline `<style>` or CSS custom properties. Ensure element IDs and CSS variable names match `/[^a-zA-Z0-9_-]/g`, and reject color strings containing CSS breakout characters (`/;|{|}|\[|\]|"|'|<|>|\\/`) or `url()` constructs.
